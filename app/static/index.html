EYNƏK VTO
StudioAdmin

Şəkildən virtual eynək sınağı

Satıcı 3 məhsul şəkli yükləyir: öndən, soldan, sağdan. Sistem fonu silir, linzaları şəffaf edir, çərçivənin real ölçüsünü hesablayır və 3D qollar qurur. Alıcı kamerada başını çevirdikdə eynək də onunla birlikdə dönür.

Öz məhsulunu yüklə

Sayta qoşmaq

1. Səhifəyə SDK skriptini əlavə edin (data-store = mağaza ID):


        
2. Düymə əlavə edin. data-eynek-hide-missing olsa, VTO-su olmayan məhsulda düymə gizlənir:

        
<button data-eynek-vto="SKU" data-eynek-hide-missing>Üzündə yoxla</button>

        
React / SPA üçün JavaScript API:

        
EynekVTO.open({ sku: "SKU" });
EynekVTO.isAvailable("SKU").then((ok) => { /* düyməni göstər */ });
EynekVTO.on("add-to-cart", ({ sku }) => addToCart(sku));

// TINT ilə eyni element interfeysi:
// <eynek-vto variant-id="SKU"></eynek-vto>  →  document.querySelector("eynek-vto").open()

      


      

        
Server API (marketplace inteqrasiyası)

        
POST /v1/products              X-Api-Key: …   multipart: sku, name, sizes=49-18-142, front, left, right
GET  /v1/products              X-Api-Key: …   mağazanın bütün VTO məhsulları
DELETE /v1/products/{sku}      X-Api-Key: …
POST /v1/upload-tokens         X-Api-Key: …   {"seller": "satıcı-id"} → satıcı üçün /studio?token=… linki
GET  /v1/stores/{store}/products/{sku}        açıq: VTO manifesti (404 = VTO yoxdur)

        

          Marketplace-də satıcı paneli /v1/upload-tokens ilə link alır və studionu açır. Satıcı yalnız öz
          məhsullarını görür və dəyişir.
